
# fe

A simple terminal file explorer written in Rust.

## Installation

### Linux / macOS

```bash
curl -fsSL https://raw.githubusercontent.com/Jonah610/file-explorer/main/install.sh | sh
```

### Windows (PowerShell)

```powershell
irm https://raw.githubusercontent.com/Jonah610/file-explorer/main/install.ps1 | iex
```

## Usage

```bash
fe
```
